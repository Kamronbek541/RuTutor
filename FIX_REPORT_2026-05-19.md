# Отчет по повторной полной проверке RuTutor

Дата: 2026-05-19

## Исправлено по замечаниям из переписки

1. <b>Письмо ИИ больше не пропадает</b>
   - Бот больше не удаляет сообщение ученика с письменным ответом в КТП-письме.
   - В ответе проверки теперь показывается блок `Текст ученика`.
   - Ниже отдельно показывается `Исправленный вариант`, комментарии, советы и мини-задание.

2. <b>Словарик доступен прямо во время Письма ИИ</b>
   - В режиме письма появилась кнопка `🃏 Словарик`.
   - Из словаря можно вернуться кнопкой `✍️ К письму`.
   - Режим письма при этом не отменяется.

3. <b>Тема 9: Деепричастие переписана вручную</b>
   - Добавлена правильная теория по деепричастию.
   - Добавлены 12 проверенных вопросов практики.
   - Добавлены 8 проверенных вопросов мини-контрольной.
   - Добавлен словарик и письменное задание.
   - Встроенный пакет урока теперь имеет приоритет над старым AI-кешем, поэтому старая ошибочная версия из базы не будет показываться.

4. <b>Прогресс ученика стал видимым</b>
   - В КТП добавлена кнопка `📈 Мой прогресс`.
   - Показывается XP, уровень, прогресс по семестрам, общее число пройденных уроков, число письменных попыток и уроки в работе.

5. <b>Лидеры защищены от фарма одной темы</b>
   - В КТП практика и контрольная больше не дают XP за бесконечные повторы.
   - XP начисляется только за новый лучший результат.
   - Бонус за сданную контрольную дается только при первом зачете.
   - Письмо ИИ дает XP за первую попытку или за улучшение лучшего балла.
   - Старые тренажеры, контрольные и классные уроки тоже больше не дают повторный XP за уже пройденное.

6. <b>Вопросы теперь перемешиваются</b>
   - В КТП перемешивается порядок вопросов.
   - В каждом вопросе перемешиваются варианты ответов.
   - Правильный индекс ответа пересчитывается автоматически.
   - На разных телефонах/у разных учеников порядок будет отличаться.

7. <b>Письменные ответы в других режимах тоже стали понятнее</b>
   - В письменных заданиях тренажеров и в ДЗ класса теперь сохраняется/показывается исходный текст ученика.
   - AI-текст экранируется перед отправкой в Telegram HTML, чтобы случайные символы `<` и `>` не ломали сообщение.

## Дополнительные исправления

- Подсказки в КТП продолжают списывать XP только после проверки баланса.
- Повторные прохождения без улучшения теперь явно пишут: `XP не начислен`.
- Рекомендации по ошибкам `syntax` и `punctuation` теперь ведут также к урокам по деепричастию и деепричастному обороту.
- Добавлены тесты для перемешивания вопросов и для валидности урока `s2_09`.
