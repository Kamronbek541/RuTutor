# Отчет по исправлениям RuTutor

Дата: 2026-05-22

## Что было исправлено

1. <b>Проблема с генерацией уроков</b>
   - Для критичных тем добавлены ручные стабильные пакеты вместо ненадежной AI-генерации:
     - `s1_03` — Фразеологизмы;
     - `s1_04` — Состав слова;
     - `s1_05` — Способы словообразования;
     - `s2_09` — Деепричастие.
   - Эти пакеты теперь имеют приоритет над старым AI-кешем из базы.
   - В каждом пакете: 12 вопросов практики, 8 вопросов контрольной, теория, словарик, письмо и рекомендации.

2. <b>Исправлены вопросы с неправильными ключами</b>
   - Добавлен локальный ремонт типичных ошибок AI:
     - `тихо` → правильная сравнительная степень `тише`;
     - двусмысленные местоимения заменяются на однозначный вопрос;
     - `От слова «семья» суффиксальным способом` теперь исправляется на ответ `семейный`, а не `суффиксальный`.
   - Усилен промпт генерации: AI обязан внутренне проверять, что есть ровно 4 уникальных варианта и ровно 1 правильный ответ.
   - Добавлено правило: если вопрос просит выбрать слово, correct должен быть словом; если просит способ, correct должен быть способом.

3. <b>Финальный разбор стал понятнее</b>
   - Старый блок `Правильные ответы` мог выглядеть так, будто у вопроса два правильных ответа, потому что рядом стояли красные/зеленые значки.
   - Теперь блок называется `Ключ ответов`.
   - В ключе больше нет красных/зеленых значков: это просто список правильных ответов.
   - Ошибки ученика остаются отдельным блоком выше: `Твой ответ` / `Правильно`.

4. <b>Аналитика класса теперь на русском</b>
   - Исправлены склеенные AI-теги вроде:
     - `Verb,aspect`;
     - `Agreement,aspect,verb`;
     - `Reflexive`.
   - Теперь они показываются по-русски:
     - `Глагол / Вид глагола`;
     - `Согласование прил. с сущ. / Вид глагола / Глагол`;
     - `Возвратные глаголы`.
   - Новые ошибки теперь сохраняются в базу уже нормализованными тегами.

5. <b>Дополнительно проверена устойчивость тестов</b>
   - Проверка индекса правильного ответа.
   - Проверка уникальности вариантов.
   - Проверка ручных пакетов уроков.
   - Проверка русификации тегов.
