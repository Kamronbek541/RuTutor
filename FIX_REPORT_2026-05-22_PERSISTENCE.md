# Отчет по сохранению лидеров и уроков RuTutor

Дата: 2026-05-22

## Что исправлено

1. База больше не привязана к папке с кодом.
   - Раньше бот использовал `bot.db` рядом с файлами проекта.
   - Если запускалась новая папка после обновления zip/GitHub, создавалась пустая база.
   - Из-за этого пропадали лидеры, прогресс, доп. темы и кэш уроков, поэтому снова требовался `/prewarm`.

2. Добавлен постоянный путь для базы.
   - По умолчанию Windows: `%LOCALAPPDATA%\RuTutor\bot.db`.
   - Можно вручную задать путь через `RUTUTOR_DB_PATH` или `BOT_DB_PATH`.
   - Можно задать папку данных через `RUTUTOR_DATA_DIR`.

3. Добавлена автоматическая миграция старой базы.
   - Если постоянной базы еще нет, бот ищет старый `bot.db`.
   - Поддерживается явный путь `RUTUTOR_LEGACY_DB_PATH` или `BOT_LEGACY_DB_PATH`.
   - При нахождении старой базы бот переносит ее через SQLite backup, сохраняя пользователей, XP, лидеров, KTP-кэш, прогресс и доп. темы.

4. Уроки и темы теперь переживают обновления кода.
   - `ktp_lesson_cache` сохраняется в постоянной базе.
   - `custom_topics` сохраняются в постоянной базе.
   - `/prewarm` не нужен после каждого обновления, если база уже была перенесена.

5. Добавлена админ-команда `/dbstatus`.
   - Показывает путь к базе.
   - Показывает количество пользователей, сохраненных уроков, доп. тем и строк прогресса КТП.
   - Это нужно, чтобы быстро проверить, что бот смотрит в старую/постоянную базу, а не в пустую.

## Важно

Если старая база еще лежит рядом со старой версией бота, новая версия перенесет ее сама при первом запуске.
Если старую `bot.db` уже удалили, код не сможет восстановить данные из воздуха. Тогда нужно вернуть старый файл базы из резервной копии и указать путь через `RUTUTOR_LEGACY_DB_PATH`.
