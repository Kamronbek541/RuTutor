# RuTutor — Telegram-бот для обучения русскому языку

Бот для колледжа: учебный план (КТП) на 54 урока, тренажёры по морфологии,
проверка письменных работ ИИ и панель преподавателя с аналитикой по классу.

Стек: Python 3 · pyTelegramBotAPI (long polling) · SQLite · OpenAI API · Railway.

| | |
|---|---|
| Репозиторий | `github.com/Kamronbek541/RuTutor` |
| Ветка | `main` — деплой на Railway автоматический при пуше |
| Запуск | `python bot.py` |
| Тесты | `python3 -m unittest discover -s tests` — **60 тестов** |

## Как это устроено

```
bot.py            точка входа: меню, тренажёры, входной тест, профиль, экраны XP
ktp_handlers.py   учебный план: урок, практика, мини-контрольная, письмо с ИИ
class_handlers.py уроки класса по расписанию (устаревший режим)
admin.py          админ-панель, панель преподавателя, экспорт, эксплуатация
ai.py             обращения к OpenAI + рукописные пакеты уроков
storage.py        SQLite: пользователи, прогресс, журнал XP, классы, настройки
xp_rules.py       все константы XP и текст правил (единый источник правды)
quiz_utils.py     нормализация вопросов, перемешивание, разбор ответов
question_reports.py  кнопка «Ошибка в вопросе» и уведомление админам
auto_backup.py    еженедельная копия базы фоновым потоком
content.py        тренажёры: теория и задания
class_content.py  расписание уроков класса
ktp_plan.py       список 54 уроков учебного плана
utils.py          подписи тегов ошибок, названия уроков
doc_parser.py     чтение Word/PDF при загрузке упражнений
```

Подробности архитектуры и подводные камни — в [CLAUDE.md](CLAUDE.md).

## Команды

### Ученик

| Команда | Что делает |
|---|---|
| `/start` | Главное меню |
| `/join КОД` | Присоединиться к классу |
| `/myid` | Узнать свой Telegram ID |

### Преподаватель

| Команда | Что делает |
|---|---|
| `/teach КОД` | Стать преподавателем класса (один раз) |
| `/teacher` | Панель: XP по урокам, ученики, выключатель ИИ, выгрузка |

### Администратор

| Команда | Что делает |
|---|---|
| `/admin` | Полная панель: классы, пользователи, рассылка, экспорт, жалобы |
| `/dbstatus` | Состояние базы: постоянное ли хранилище, счётчики, список админов |
| `/dbbackup` | Прислать файл базы в чат |
| `/cleanup_alerts` | Убрать технические сообщения из чатов админов |
| `/xp_backfill` | Пересчитать историю XP по урокам (обычно не нужно) |
| `/prewarm [N]` | Заранее сгенерировать уроки |
| `/rebuild [семестр]` | Перегенерировать и вычитать уроки |

## Запуск локально

```bash
pip install -r requirements.txt
cp .env.example .env   # заполнить BOT_TOKEN, OPENAI_API_KEY, OPENAI_MODEL
python bot.py
```

⚠️ Нельзя запускать локально с тем же `BOT_TOKEN`, что на Railway: Telegram
отдаёт обновления только одному получателю, и оба экземпляра начнут падать
с ошибкой `409 Conflict`. Для локальной отладки заведите отдельного бота.

Тесты работают без токенов и без сети:

```bash
python3 -m unittest discover -s tests
```
